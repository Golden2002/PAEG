## 2. Layer 0：宪法与安全层（v3.0 新增）

### 2.1 PAEG 宪法

借鉴 **Anthropic Constitutional AI** (Bai et al., 2022) 与教育领域特性：

```yaml
constitution:
  # 安全原则（优先级最高）
  safety:
    - "不评判政治立场，只教'如何分析'"
    - "不教任何具体宗教信仰，只教'如何理解'"
    - "不给医疗/法律具体建议，只给'通识层面'"
    - "对未成年学生有额外约束"

  # 教育原则（核心）
  pedagogy:
    - "宁可不给答案，也要引导学生思考"
    - "承认错误时显式说明，不掩盖"
    - "对每个学生保持尊重，不论其能力"
    - "对失败的学生，鼓励优先于批评"
    - "对隐私敏感数据，绝不外泄"

  # 自我更新原则
  self_update:
    - "新策略需 ≥3 个独立证据才采纳"
    - "新知识入库需可信度 ≥0.8"
    - "画像修改用 EMA α=0.3 避免过拟合"
    - "所有更新对用户可见"
    - "7 天观察期内可自动回滚"
```

### 2.2 SafetyMiddleware 实现

```python
class SafetyMiddleware:
    """PAEG 安全中间件（v3.0 借鉴 CAI 宪法机制）。"""

    def __init__(self, constitution: dict):
        self.constitution = constitution

    def check(self, content: str, learner: LearnerProfile) -> tuple[bool, str]:
        """对内容做安全审查。"""
        # 1. 政治敏感
        if self.is_political(content) and not self.is_analysis_request(content):
            return False, "我们换个话题吧。"

        # 2. 医疗法律
        if self.is_medical_legal(content) and not self.is_general_request(content):
            return False, "这类具体问题建议你咨询专业人士。"

        # 3. 儿童保护
        if learner.age < 18 and self.is_sensitive(content):
            self.log_to_safety_queue(content, learner.id)
            return False, "这个话题我暂时帮不到你。"

        return True, ""
```

## 3. Layer 5：教学推理层（v3.0 强化）

### 3.1 从"5 子代理"到"5 子代理 + 3 元组"

v3.0 在 v2.0 基础上增加 **3 元组**（借鉴 GenMentor / KELE / SocraticLM）：

| 子代理 | 职责 | 输入 | 输出 |
|---|---|---|---|
| **Diagnostor**（诊断） | 测学生"知道什么、缺什么" | 学生问题 + 画像 | 学习状态向量 |
| **Planner**（计划） | 设计本次教学路径 | 诊断 + 画像 + 教学法库 | 步骤序列 |
| **Presenter**（呈现） | 多模态讲解 | 计划步骤 + 画像 | 讲解内容 |
| **Evaluator**（评估） | 检验学生是否真懂 | 学生反应 | 掌握度评估 |
| **Adapter**（调整） | 实时调整（难度/风格/鼓励） | 评估 + 反馈 | 调整建议 |

**新增元组**：

| 元组 | 角色 | 借鉴来源 |
|---|---|---|
| **Consultant** | 长期路径规划、知识图谱导航 | GenMentor, ReAL/GenAL |
| **Teacher** | 对话执行（含 Socratic prompt） | KELE, SocraticLM |
| **Content** | 项目检索、改写、验证 | Khanmigo Math Agent, MATHia |
| **Learner Profiler** | 持续更新认知+情感状态 | GenMentor |
| **Learner Simulator** | 角色扮演用于稀疏反馈 | GenMentor |

### 3.3 自适应干预 v3.0：Contextual Bandit

借鉴 **Springer 2025 (Real-time cognitive & emotional state tracking in ITS)**：

```python
def select_intervention(affect_state, cognition_state, history):
    """Constrained Contextual Bandit 选择干预方式。

    4 类干预：
    - 内容调整（confusion 高）
    - 界面调整（frustration 高）
    - 元认知提示（engagement 高）
    - 动机支持（boredom 高）
    """
    state_vector = encode_state(affect_state, cognition_state, history)

    # 规则 + Bandit 组合
    if affect_state['frustration'] > 0.7:
        return "界面调整：降低难度 + 鼓励"
    if affect_state['confusion'] > 0.6:
        return "内容调整：换种讲解法"
    if affect_state['engagement'] > 0.8 and cognition_state['mastery'] > 0.7:
        return "元认知提示：让学生反思"
    if affect_state['boredom'] > 0.6:
        return "动机支持：联系实际生活"
    return "继续"
```

## 4. Layer 6：自我更新层（v3.0 升级）

### 4.1 v3.0 三大组件（借鉴 SOTA）

| 组件 | 借鉴 | 在 PAEG 中的实现 |
|---|---|---|
| **Immutable Skill Library** | Voyager (NeurIPS 2023) | 知识库节点 append-only + content-hash snapshot |
| **Constitutional Pre-check** | Anthropic CAI | Layer 0 宪法对每次更新预检 |
| **Held-out Eval Post-check** | AgentGit + MetaReflection | 离线批处理在冻结测试集上评估候选 |
| **Hashed Canary + Rollback** | Platos, Agentium | 新策略对 5-10% 学生试运行 7 天 |

### 4.2 v3.0 自我更新流程

```
每次会话后：
  1. 元认知反思 → 生成"更新候选"
  2. 宪法预检 → 检查是否违反 §2.1 的原则
     违宪 → 拒绝（写入 metacog_log）
  3. 证据计数 → 更新 candidate.evidence_count
  4. EMA 画像更新 → 学习者状态更新
  5. 版本日志 → 写入 git-like 存储

每周批处理：
  1. 统计候选（≥3 证据 → 候选策略）
  2. 离线评估（held-out 测试集）
  3. 评估通过 → canary 部署到 5-10% 学生
  4. canary 失败 → 自动回滚
  5. canary 成功 → 全量部署
```

### 4.3 实施细节

```python
class SelfUpdaterV3:
    """自我更新器 v3.0（Voyager 风格 + CAI + MetaReflection）"""

    # 保守阈值（不变）
    MIN_EVIDENCE_FOR_STRATEGY = 3
    MIN_CONFIDENCE_FOR_KNOWLEDGE = 0.8
    PROFILE_EMA_ALPHA = 0.3
    ROLLBACK_WINDOW_DAYS = 7

    def incremental_update(self, session):
        # 1. 元认知反思
        reflection = self.reflector.summarize(session)

        # 2. 宪法预检（v3.0 新增）
        if not self.constitution.check(reflection):
            self.metacog_log.append({
                "type": "rejected",
                "reason": "violates_constitution",
                "reflection": reflection,
            })
            return

        # 3. 候选更新
        if reflection.success:
            self._add_strategy_candidate(reflection)
        if reflection.new_knowledge:
            self._add_knowledge_candidate(reflection)

        # 4. EMA 画像
        self._update_profile_ema(session)

        # 5. 版本日志
        self._commit("incremental_update", session)

    def batch_update(self):
        """每周批处理：评估候选 + canary 部署。"""
        # 1. 候选筛选（≥3 证据）
        candidates = [s for s in self.strategy_candidates
                      if s.evidence_count >= self.MIN_EVIDENCE_FOR_STRATEGY]

        # 2. 离线评估（held-out 测试集）
        evaluated = []
        for c in candidates:
            score = self.offline_evaluator.evaluate(c)
            evaluated.append({"candidate": c, "score": score})

        # 3. 部署通过的候选（canary 5-10%）
        for ev in evaluated:
            if ev["score"] >= self.acceptance_threshold:
                self._canary_deploy(ev["candidate"], traffic_pct=0.10)

        # 4. 回滚监控
        self._monitor_canary_and_rollback()
```

## 6. 端到端数据流 v3.0（"什么是熵"）

```
学生输入："什么是熵？"
   ↓
[前端 → POST /api/teach]
   ↓
[后端 Layer 1] 接收请求 + 调取学习者画像
   ↓
[Layer 0] SafetyMiddleware.check() → OK
   ↓
[Layer 5 Diagnostor] 读画像 + 前置检查 → ready_to_teach=True
   ↓
[Layer 5 Planner]
   - 选策略：物理类比 + 视觉图
   - 选语气：rigorous_cold (2:70%)
   - 输出：3 步教学计划
   ↓
[Layer 5 Presenter] 生成 3 步内容（含丰富字段）
   ↓
[Layer 5 Evaluator] 每步后评估
   ↓
[Layer 5 Adapter] 必要时调整（v3.0: Contextual Bandit）
   ↓
[Layer 6] 反思 + 宪法预检 + EMA 画像更新
   ↓
[响应返回前端] 流式推送每步内容
   ↓
[Layer 7] 主对话面板显示：
   - 世界观 badge（rigorous_cold）
   - 内容（含公式、例子、误区）
   - 评估条（3 条）
   ↓
[Layer 7 右侧面板]
   - 学习者画像更新（mastery 上升）
   - 元认知日志新条目
   - 知识图谱：熵节点高亮
   - 批处理摘要：会话+1，版本+1
```
