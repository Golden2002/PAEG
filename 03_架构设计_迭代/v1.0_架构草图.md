## 2. 五大子代理（Layer 4 核心）

PAEG 的核心是**5 个协同子代理**，每个对应一个教学环节：

| 子代理 | 职责 | 触发 | 输出 |
|---|---|---|---|
| **诊断子代理** | 探测学生"知道什么、缺什么、卡在哪" | 新会话开始 / 学生答错时 | 学习状态向量 |
| **计划子代理** | 设计本次教学路径（按 SKILL.md 加载教学法） | 诊断完成后 | 教学计划（步骤序列） |
| **呈现子代理** | 多模态讲解（文字+图+视频+交互） | 计划中每个"呈现"节点 | 讲解内容 |
| **评估子代理** | 检验学生是否真懂（出题/对话/任务） | 每次讲解后 | 掌握度评估 |
| **调整子代理** | 实时调整（难度降一档 / 换种讲解法 / 鼓励） | 评估后或学生显式反馈 | 调整建议 |

### 2.1 子代理间数据流

```
诊断 → 计划 → 呈现 → 评估 → 调整
  ↑                              ↓
  └──────────────────────────────┘
        (闭环)
```

每次"调整"可触发新"诊断"或新"计划"。

## 6. 自我更新机制（Layer 5）

### 6.1 4 类自我更新对象

| 对象 | 触发 | 内容 |
|---|---|---|
| **知识库** | 每周批处理 + 实时 RAG | 新学科事实、案例、参考文献 |
| **教学策略库** | 每次教学后增量 | "这次 X 策略对 Y 学生有效" |
| **学习者画像** | 每次对话后增量 | 进步轨迹、情绪趋势、兴趣更新 |
| **元认知日志** | 每次反思 | "我刚才哪里教得不好" |

### 6.2 自我更新的实现

```python
# 简化伪代码
def reflect_and_update(session_data):
    # 1. 元认知反思
    reflection = reflector.summarize(session_data)
    # "这次在讲'熵'时，我用了太多公式，学生明显卡住。下次先用类比。"

    # 2. 增量更新
    if reflection.quality_score < 0.6:
        # 教学失败 → 更新策略库（添加"避免"标记）
        strategy_kb.add_avoid(reflection.avoid_patterns)
    else:
        # 教学成功 → 提炼模式
        strategy_kb.add_pattern(reflection.success_patterns)

    # 3. 画像更新
    learner_profile.update_progress(session_data.subject, session_data.score)
    learner_profile.update_emotion(session_data.emotion_signals)

    # 4. 元认知日志
    metacog_log.append(reflection)

    # 5. 同步云端
    sync_to_cloud(learner_profile, strategy_kb, metacog_log)
```

### 6.3 自我更新的"安全三原则"实现

- **版本化**：所有写入走 git-like 存储；可回滚到任意版本
- **A/B 测试**：新策略先小范围试；CRDT-like 冲突合并
- **用户可见**：学生可访问自己的"被更新历史"

## 8. 关键数据流示例：讲"什么是熵"

```
学生输入："什么是熵？"
   ↓
[RECEIVE_INPUT]
   ↓
[RETRIEVE_PROFILE] — 小李，高二，理科偏好，视觉型
   ↓
[CLASSIFY_INPUT] → TEACHING
   ↓
[TEACHING 子状态机]
   ↓
[DIAGNOSE] — 问 2 个前置问题：是否懂"系统"和"概率"？→ 都懂
   ↓
[PLAN] — 选策略：物理类比（卡诺热机） + 视觉图（分子无序度）
   ↓
[PRESENT]
  ├─ 用 2 分钟讲"一杯热水的热量分布"（直觉）
  ├─ 给出公式 S = k·lnΩ（形式）
  └─ 用"扔 100 个球的盒子"动画（视觉）
   ↓
[PRACTICE] — 让小李解释"为什么冰融化熵增加"
   ↓
[EVALUATE] — 检查答案质量：85/100
   ↓
[ADAPT] — 继续深入 → 推"信息熵"
   ↓
[REFLECT]
  - 成功：物理类比对理科生有效
  - 元认知：下次对文科生可改用"信息的不确定性"
   ↓
[UPDATE]
  - 策略库：add_pattern("理科生-物理类比")
  - 画像：小李熵 掌握度 0.85
  - 元认知日志：append
   ↓
[SYNC_TO_CLOUD]
```

## 9. 教学中的"世界观切换"机制

PAEG 必须能根据主题**自动调用合适的比例**（D1 决策）：

| 主题 | 主导世界观 | 切换规则 |
|---|---|---|
| 物理、数学、逻辑 | 2 (35%) | "冷峻理性"模式 |
| 文学、审美、现象 | 3 (35%) | "沉静内省"模式 |
| 道德、关系、品格 | 1 (20%) | "温和关怀"模式 |
| 实用、职业、应用 | 4 (10%) | "务实对话"模式 |
| 综合主题 | 加权混合 | 比例由 `worldview_blend` 字段决定 |

### 9.1 切换的实现

```python
def select_tone(theme: str, learner_state: dict) -> dict:
    if theme in PHYSICS_MATH_LOGICAL:
        return {"tone": "rigorous_cold", "ratio": {1: 0.05, 2: 0.70, 3: 0.10, 4: 0.15}}
    elif theme in AESTHETICS_PHENOMENOLOGY:
        return {"tone": "contemplative", "ratio": {1: 0.20, 2: 0.10, 3: 0.60, 4: 0.10}}
    elif theme in MORAL_RELATIONSHIP:
        return {"tone": "warm_caring", "ratio": {1: 0.50, 2: 0.20, 3: 0.20, 4: 0.10}}
    elif theme in PRACTICAL_VOCATIONAL:
        return {"tone": "pragmatic", "ratio": {1: 0.10, 2: 0.20, 3: 0.10, 4: 0.60}}
    else:
        # 默认按用户决策的全局比例
        return {"tone": "balanced", "ratio": {1: 0.20, 2: 0.35, 3: 0.35, 4: 0.10}}
```
