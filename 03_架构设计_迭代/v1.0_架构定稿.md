## 2. Layer 0：角色与安全层（新增）

### 2.1 角色切换（RoleSwitch）

PAEG 在**同一进程**内支持三种角色：

| 角色 | 触发 | 权限 | UI 特征 |
|---|---|---|---|
| **学生模式** | 默认 | 看自己的画像、教学记录、调整 | 学习界面 |
| **教师模式** | 教师认证后切换 | 看所有学生画像、班级统计、干预 | 仪表盘 |
| **家长模式** | 家长认证后切换 | 看自己孩子的画像（隐私过滤后） | 简化报告 |

### 2.2 安全中间件（SafetyMiddleware）

| 检查项 | 行为 |
|---|---|
| **政治敏感** | 不评判政治立场；只教"如何分析" |
| **宗教信仰** | 不教任何具体信仰；只教"如何理解" |
| **医疗法律** | 不给具体建议；只给"通识层面"信息 |
| **儿童保护** | 对未成年学生有额外约束；可上报 |
| **个人隐私** | 教师只能看授权学生；家长只能看自己孩子 |
| **数据导出** | 用户可导出/删除自己的全部数据 |

### 2.3 安全中间件的实现位置

```python
def safety_middleware(input_text: str, learner: Profile) -> tuple[bool, str]:
    # 1. 政治敏感检查
    if is_political(input_text) and not is_analysis_request(input_text):
        return False, "我们换个话题吧。"

    # 2. 医疗法律检查
    if is_medical_legal(input_text) and not is_general_knowledge_request(input_text):
        return False, "这类具体问题建议你咨询专业人士。"

    # 3. 儿童保护
    if learner.age < 18 and is_sensitive_topic(input_text):
        log_to_safety_queue(input_text, learner.id)
        return False, "这个话题我暂时帮不到你。"

    return True, ""
```

### 4.3 多子代理协调协议（解决 Q1）

PAEG 采用**"共享语义状态 + 独立执行上下文"双轨制**：

| 元素 | 共享 vs 独立 |
|---|---|
| **共享** |  |
| 教学计划（Plan） | ✅ 所有子代理看到 |
| 学习者画像 | ✅ 所有子代理看到 |
| 元认知日志 | ✅ 共享写入 |
| **独立** |  |
| 各子代理的执行历史 | ❌ 各自独立（避免上下文污染） |
| 各子代理的工具调用日志 | ❌ 各自独立（便于调试） |
| 各子代理的中间思考 | ❌ 各自独立 |

```python
class SharedState:
    plan: TeachingPlan
    profile: LearnerProfile
    metacog_log: MetaCogLog
    current_step: int

class SubagentContext:
    system_prompt: str
    tools: list
    history: list  # 独立
    intermediate_thoughts: list  # 独立
    tool_logs: list  # 独立
```

每个子代理调用：`result = subagent.run(shared_state, current_task) → returns action_plan`

主控制器根据 action_plan 决定下一步调用哪个子代理。

### 4.4 子代理的"消息隔离"实现

```python
# 防止子代理的中间过程污染主代理
def subagent_isolated_run(subagent, task):
    own_history = [{"role": "user", "content": task}]
    while True:
        response = subagent(own_history, subagent.tools)
        if not response.tool_use:
            return response.text
        # 执行工具，结果回填到 own_history
        # 关键：own_history 不进入主历史
```

### 6.2 自我更新实现细节

```python
class SelfUpdate:
    def __init__(self, store, schedule):
        self.store = store  # git-like storage
        self.schedule = schedule  # cron-like scheduler
    
    def incremental_update(self, session_data):
        # 1. 元认知反思
        reflection = self.reflector.summarize(session_data)
        # 2. 画像增量
        self.profile_updater.update(session_data)
        # 3. 策略增量
        self.strategy_updater.maybe_update(reflection)
        # 4. 元认知日志
        self.metacog_log.append(reflection)
        # 5. 同步云端
        self.cloud_sync.push()
        # 6. 写 git commit
        self.store.commit(f"session_{session_data.id}")
    
    def batch_update(self):
        # 周日 2:00 跑
        # 1. 整合所有本周经验
        # 2. 重新整理知识库（去重、补全）
        # 3. （条件允许时）做 LoRA 微调
        # 4. 写 git tag
        self.store.tag(f"week_{week_id}")
    
    def rag_search(self, query):
        # 实时外部检索
        return self.vector_store.search(query)
```

### 6.3 自我更新的"安全三原则"

- **版本化**：所有写入走 git-like 存储
- **A/B 测试**：新策略先小范围试
- **用户可见**：学生可查看"我如何被更新的"

```python
# 简化的版本化实现
class VersionedStore:
    def __init__(self, path):
        self.path = path
        self.history = []  # 模拟 git log
    
    def commit(self, data, message):
        version = len(self.history) + 1
        self.history.append({"version": version, "data": copy(data), "message": message})
        return version
    
    def rollback(self, version):
        target = next(h for h in self.history if h["version"] == version)
        return target["data"]
    
    def history(self):
        return self.history
```

### 6.4 元认知反思的三段式（解决 Q2）

| 粒度 | 频率 | 内容 |
|---|---|---|
| **每步反思** | 每个教学循环结束 | "刚才的呈现是否清楚？学生是否理解？" |
| **每会话反思** | 整个会话结束 | "本次教学目标的达成度？需要更新哪些策略/画像？" |
| **每周反思** | 批处理时 | "本周的教学模式总结；识别反复出现的问题；触发新策略 A/B 测试" |

```python
class MetaCognition:
    def per_step_reflect(self, step_result):
        return f"刚才的呈现：{step_result.presentation[:100]}；学生反应：{step_result.student_response[:100]}；我的判断：{step_result.assessment}"
    
    def per_session_reflect(self, session):
        success_rate = session.scores.mean()
        weak_points = [s.topic for s in session.scores if s.score < 0.6]
        return {
            "success_rate": success_rate,
            "weak_points": weak_points,
            "improvements": [f"下次加强 {p}" for p in weak_points]
        }
    
    def weekly_reflect(self, sessions):
        # 找出反复出现的问题
        patterns = Counter(s.metacog_note for s in sessions)
        return {
            "recurring_issues": patterns.most_common(5),
            "new_strategy_proposals": self.propose_new_strategies(patterns)
        }
```

## 8. 多模态教学（解决 Q3）

### 8.1 多模态策略

PAEG 采用**"案例图预生成 + 解释图实时生成"** 混合模式：

| 图类型 | 生成方式 | 成本 | 适用 |
|---|---|---|---|
| 经典概念图（抛物线、分子运动） | 预生成库 | 0（缓存） | 高频复用 |
| 个性化案例图（"小李的笔记") | 实时生成 | 每次 | 一次性 |
| 解释性图（"为什么是这样") | 实时生成 | 每次 | 引导理解 |

### 8.2 实现

```python
class MultiModalPresenter:
    def present_concept(self, concept_id, learner):
        # 1. 查图库
        cached_image = self.image_cache.get(concept_id)
        if cached_image:
            return cached_image
        # 2. 实时生成
        prompt = f"为学习者 {learner.name}（{learner.cognitive_style}）生成'{concept.name}'的解释图"
        return self.image_gen.generate(prompt)
```

def select_tone(theme: str, learner_state: dict) -> dict:
    """根据主题选择教学语气。"""
    # 主题分类
    if theme in {"physics", "math", "logic", "cs"}:
        return {
            "tone": "rigorous_cold",
            "ratio": {1: 0.05, 2: 0.70, 3: 0.10, 4: 0.15},
            "system_suffix": "你冷静、严谨、强调证据。"
        }
    elif theme in {"literature", "aesthetics", "phenomenology"}:
        return {
            "tone": "contemplative",
            "ratio": {1: 0.20, 2: 0.10, 3: 0.60, 4: 0.10},
            "system_suffix": "你沉静、邀请内省、保留沉默空间。"
        }
    elif theme in {"ethics", "relationship", "character"}:
        return {
            "tone": "warm_caring",
            "ratio": {1: 0.50, 2: 0.20, 3: 0.20, 4: 0.10},
            "system_suffix": "你温和、关怀、像过来人分享。"
        }
    elif theme in {"career", "skill", "application"}:
        return {
            "tone": "pragmatic",
            "ratio": {1: 0.10, 2: 0.20, 3: 0.10, 4: 0.60},
            "system_suffix": "你务实、对话式、强调'试试看'。"
        }
    else:
        # 默认按用户决策的全局比例
        return {
            "tone": "balanced",
            "ratio": {1: 0.20, 2: 0.35, 3: 0.35, 4: 0.10},
            "system_suffix": ""
        }
