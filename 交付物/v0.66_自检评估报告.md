## 三、连通性核查（用户核心诉求）

### 已打通的链路
```
用户短指令"极限"
  → [意图补全] 推断学段/学科/深度
  → [讲义] generate_handout（6段教学，注入 KB+物料+联网）
  → [大纲] _outline_from_handout
  → [讲稿] script_service（授课式，L0-L3 语言规范）
  → [PPT] 与讲稿同源（key_points 注入）
  → [manim] 动画渲染 + 配音跟随
  → [视频] compose_with_slots 融合合成（72s）
```
```
思维导图（按钮触发）→ KB + 用户物料 + 联网 三路注入
找答案 → 统一资源门面（联网+KB+Library）
教学每步 → collect_all_resources 注入 Presenter
```

### 待优化（非断裂）
- `Library/linguistics|Math|Philosophy|Simone Weil/`：仅登记 raw_files 未进检索（P2）
- `KnowledgeBase/facts`：已被 knowledge_map/teach_stream 接入（v0.66 前是死数据）
- server.py 4442 行 > 4000（结构性，Phase 3 蓝图规划中）
- pyright 检查工具未安装（环境）
