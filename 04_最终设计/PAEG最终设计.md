## 1. 一句话定义

**PAEG = 一个拥有 5 个协同子代理、4 类知识库、3 段反思机制、2 种画像深度的教育者智能体；它能教高中+本科的学科知识与技能、能教人之为人的审美/道德/思辨/生命现象学素养；它能从每次交互中自我反思、增量学习、版本化更新；同时保持安全、隐私、可回滚。**

## 4. 最终架构（6 层）

```
PAEG
├── Layer 0: 角色与安全层（RoleSwitch + SafetyMiddleware）
├── Layer 1: 基础模型与工具层（17 个工具 + 多模型）
├── Layer 2: 上下文与记忆层（含学习者画像 + 长期记忆）
├── Layer 3: 知识与技能层（4 库 + Skill 注册表）
├── Layer 4: 教学推理层（5 个子代理 + 协调协议）
└── Layer 5: 自我更新层（4 类对象 + 3 段反思）
```

详细见 `v1.0_架构定稿.md` §1-§13。

## 5. 5 个子代理

| 子代理 | 职责 | 关键 API |
|---|---|---|
| **诊断子代理** | 测学生"知道什么、缺什么、卡在哪" | 输入：学生问题 + 画像；输出：学习状态向量 |
| **计划子代理** | 设计本次教学路径 | 输入：诊断 + 画像 + 教学法库；输出：步骤序列 |
| **呈现子代理** | 多模态讲解 | 输入：计划步骤 + 画像；输出：讲解内容 |
| **评估子代理** | 检验学生是否真懂 | 输入：学生反应；输出：掌握度评估 |
| **调整子代理** | 实时调整（难度/风格/鼓励） | 输入：评估 + 反馈；输出：调整建议 |

详细 API 见 `v2.0_架构迭代.md` §1。

## 6. 4 类知识库

| 库 | 主要字段 | 规模目标 |
|---|---|---|
| **学科知识库** | subject_node (id, level, prerequisites, variants, misconceptions, strategies, examples, exercises, references) | 高中 9 科 + 本科 12 个一级学科 |
| **素养知识库** | humanity_node (dimension, traditions, teaching_modes, worldview_fit) | 4 维度 × 多个传统 |
| **教学法库** | teaching_strategy (steps, when_to_use, examples, success_metrics) | 30+ 策略 |
| **案例库** | case (type, used_in, content, why_good) | 100+ 案例 |

详细 schema 见 `v1.0_架构定稿.md` §5。

## 7. 自我更新机制

### 7.1 4 类更新对象

| 对象 | 触发 | 频率 |
|---|---|---|
| 知识库 | 批处理 + RAG | 周/实时 |
| 教学策略库 | 反思器 | 每次会话 |
| 学习者画像 | 适配器 | 每次会话 |
| 元认知日志 | 反射器 | 每次会话 |

### 7.2 3 段反思

- **每步反思**（每个教学循环结束）
- **每会话反思**（整个会话结束）
- **每周反思**（批处理时）

### 7.3 安全三原则

- **版本化**：所有写入走 git-like 存储
- **A/B 测试**：新策略先小范围试
- **用户可见**：学生可查看"我如何被更新的"

详细见 `v1.0_架构定稿.md` §6。

## 8. 教学风格自动切换（关键设计）

PAEG 在 4 种语气间自动切换：

| 语气 | 主导世界观 | 比例 | 适用主题 |
|---|---|---|---|
| **rigorous_cold** | 古典自由主义+科学理性 | 70% | 物理、数学、逻辑、计算机 |
| **contemplative** | 现象学+东方智慧 | 60% | 文学、美学、现象学 |
| **warm_caring** | 儒家+人本主义 | 50% | 伦理、关系、品格 |
| **pragmatic** | 实用主义+多元主义 | 60% | 职业、技能、应用 |
| **balanced** | 全比例 | 1:0.20, 2:0.35, 3:0.35, 4:0.10 | 默认 |

详见 `v2.0_架构迭代.md` §7。

## 9. 端到端示例（5 个学科）

| 学科 | 输入 | 主导语气 | 关键策略 |
|---|---|---|---|
| 物理（熵） | "什么是熵？" | rigorous_cold | 物理类比 + 视觉图 |
| 文学（特洛伊） | "为什么特洛伊战争持续十年？" | contemplative | 叙事 + 现象学反思 |
| 道德（电车） | "电车难题该拉开关吗？" | warm_caring | 苏格拉底式对话 |
| 数学（负负得正） | "为什么负负得正？" | rigorous_cold | 定义法 + 直观 |
| 生命现象学 | "为什么人会感到孤独？" | warm_caring + contemplative | 陪伴 > 答案 |

详见 `v2.0_架构迭代.md` §6。
