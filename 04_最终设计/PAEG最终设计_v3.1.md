## 1. 一句话定义

**PAEG = 一个拥有 5 个协同子代理 + Consultant/Teacher/Content 三元组、4 类知识库（高中+本科+考研+素养）、3 段反思机制、Layer 0 教育宪法、Layer 6 Voyager-style immutable 自进化机制、7 个 GUI 组件的教育者智能体；它能教高中+本科+考研的学科知识与技能、能教人之为人的审美/道德/思辨/生命现象学素养；它能从每次交互中自我反思、宪法预检、增量学习、版本化更新、可观测可回滚；同时保持安全、隐私、保守渐进。**

## 7. 自我更新机制 v3.1

### 7.1 三段反思（不变）

- 每步反思（每个教学循环）
- 每会话反思（整个会话）
- 每周反思（批处理）

### 7.2 保守渐进阈值

```python
MIN_EVIDENCE_FOR_STRATEGY = 3       # ≥3 证据
MIN_CONFIDENCE_FOR_KNOWLEDGE = 0.8  # ≥0.8 可信度
PROFILE_EMA_ALPHA = 0.3             # EMA α=0.3
ROLLBACK_WINDOW_DAYS = 7            # 7 天观察期
```

### 7.3 安全三原则（不变）

- **版本化**：所有写入 git-like 存储
- **A/B 测试**：新策略先 canary 5-10%
- **用户可见**：学生可查看"我如何被更新的"

### 7.4 v3.0 升级：Voyager 风格 immutable library

每个更新写入都生成新版本号，不删除旧版本。借鉴 Voyager (NeurIPS 2023) 的 skill-as-code 思想。
