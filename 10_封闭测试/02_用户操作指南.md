# PAEG 封闭测试 · 用户操作指南（v1.0）

> **目的**：手把手教您打开 PAEG 并开始测试。共 3 种访问方式，选一种即可。
> **版本**：v1.0 · 2026-08-21

---

## 一、三种访问方式（选一种）

### 方式 A：电脑浏览器（推荐，体验最佳）

1. 打开 Chrome 或 Edge 浏览器
2. 在地址栏输入测试网址（见邀请信息，形如 `https://xxxx.trycloudflare.com`）
3. 按回车，等待页面加载（约 3-8 秒）
4. 看到 **"PAEG · 教育者智能体"** 页面 + "服务在线" 绿色标记 = 连接成功

> 💡 若显示"服务离线"或"无法访问"，请等待 1 分钟重试；仍不行则联系测试协调员。

### 方式 B：手机浏览器

1. 用手机浏览器（微信内置浏览器亦可）打开同一网址
2. 页面加载后可直接使用
3. 注意：手机端某些高级功能（如文件上传）体验可能受限，建议核心测试在电脑完成

### 方式 C：本地访问（仅限受邀在开发机旁测试）

1. 打开电脑上的 PowerShell
2. 依次执行：
```powershell
cd "D:\桌面\智能体架构与开发（含大模型）\14_教育者Agent项目\05_实现原型"
python server.py
```
3. 浏览器打开 `http://localhost:5000`

## 二、页面快速认识

打开后，您会看到：

```
┌─────────────────────────────────────────────┐
│  Émile Novis · 教育者     服务在线 ●          │
│  [登录/注册] [气象] [学科教学 ▼]             │
├─────────────────────────────────────────────┤
│  左侧：模式选择       │   右侧：对话主区域    │
│  · 学科教学（默认）   │                      │
│  · 闲聊              │   [输入你想学的内容…] │
│  · 找答案            │        [发送]        │
│  · 学习方法          │                      │
│  · 知识库            │                      │
│  · 倾诉              │                      │
└─────────────────────────────────────────────┘
```

| 区域 | 作用 |
|---|---|
| 顶部 | 登录/注册、学科/学段选择（初中/高中/本科/考研） |
| 左侧 | 六种模式切换（教学/闲聊/找答案/方法/知识库/倾诉） |
| 中央 | 对话主区域（教学、讲解都在这里） |
| 输入框 | 输入你想学的内容，回车或点发送 |
| 右上角 | 学习者画像（告诉老师你是谁） |

---

## 三、测试前 3 个准备动作

1. **登录/注册**：点击右上角"登录/注册"，注册一个测试账号（随便填即可，测试数据独立）
2. **选择学段**：顶部选择你的学段（建议"高中"，覆盖最全）
3. **选择学科**：顶部选择"数学"（物料生成效果最好）

> 不做也行——系统会用默认学段（高中）+ 自动识别学科。做了更接近真实使用。

## 四、开始第一次对话

在输入框输入：

```
你好，介绍一下你自己
```

预期：Émile 老师回应，介绍自己是教育者智能体。**能收到回复 = 一切正常，可以开始正式测试了。**

## 五、常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 页面打不开 / 服务离线 | 等 1 分钟重试；联系协调员 |
| 发送后很久没回复 | 教学讲解需 10-30 秒生成，属正常；超过 60 秒无响应再反馈 |
| 输入框是空的 / 没反应 | 刷新页面重试 |
| 不知道某个功能怎么用 | 直接写进反馈表："不会用/不知道怎么触发" |
| 想切换学科但菜单没有 | 先切换学段（本科/考研），学科菜单会变化 |
| 生成 PPT/教案后在哪下载 | 对话中会出现下载链接/按钮，点击下载 |
