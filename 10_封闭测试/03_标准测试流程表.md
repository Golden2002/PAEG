# PAEG 封闭测试 · 标准测试流程表（v1.0）

> **聚焦**：教学模块的内容生成 + 物料生成能力
> **时长**：约 30-45 分钟（15 个重点步骤 + 可选自由探索）
> **填写**：每步操作后，在"结果"列打 ✅ / ⚠️ / ❌，把感受写在"反馈"列（一句大白话即可）
> **版本**：v1.0 · 2026-08-21 · PAEG v1.2.0（§3.79）

---

## 📌 使用说明（30 秒）

1. **按顺序做**：前 15 步是重点路径，请按顺序完成（约 30 分钟）
2. **如实填写**：结果列打勾，反馈列写你的真实感受（"很清楚/没听懂/太快了/很惊喜"都行）
3. **不勉强**：某一项卡住 3 分钟没进展，标 ❌ 跳到下一步
4. **自由探索**：第 16 步起可选，测到你感兴趣为止

## 第一部分：教学讲解（内容生成 · 8 步 · 约 18 分钟）

| # | 步骤 | 怎么做 | 期望看到 | 结果 | 反馈（一句话） |
|---|------|--------|----------|:---:|----------------|
| 1 | 开始教学 | 输入「什么是导数」 | 进入教学（不是直接给答案），有"诊断→讲解"过程 | | |
| 2 | 追问深讲 | 教学后输入「再详细讲讲」 | 延续上文继续深入，不是重新开始 | | |
| 3 | 联系生活 | 输入「用生活例子解释导数」 | 用类比/例子讲解，易懂 | | |
| 4 | 检查理解 | 输入「出个题考考我」 | 出一道相关题目让你答 | | |
| 5 | 换学科 | 顶部切「物理」，输入「什么是加速度」 | 自动切到物理教学 | | |
| 6 | 因材施教 | 输入「我数学基础弱，讲慢一点」 | 后续讲解变慢、更基础 | | |
| 7 | 直接答疑 | 左侧切「找答案」，输入「能量守恒是什么」 | 直接给完整答案（不走教学流程） | | |
| 8 | 情绪陪伴 | 左侧切「倾诉」，输入「我今天有点累」 | 先回应情绪，不急着讲题 | | |

## 第二部分：物料生成（重点 · 5 步 · 约 20 分钟）

> 物料生成是本次测试的**重中之重**——请重点关注生成内容的"准确性 + 可用性"。

| # | 步骤 | 怎么做 | 期望看到 | 结果 | 反馈（一句话） |
|---|------|--------|----------|:---:|----------------|
| 9 | 生成教案 | 输入「我要备课：一元二次方程，制作教案」 | 生成完整教案（含目标/环节/板书/反思） | | |
| 10 | 教案质量 | 打开教案，检查 3 点：教学目标是否清晰 / 环节是否完整 / 能否直接拿去上课 | 三点都满足 = ✅ | | |
| 11 | 生成 PPT | 接上一步输入「再生成 PPT 大纲」 | 生成 5-7 页 PPT 大纲 | | |
