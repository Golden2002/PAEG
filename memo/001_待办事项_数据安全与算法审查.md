## 一、数据安全（待处理 · 优先级高）

### 现状
- 用户数据存储：`05_实现原型/users.json` + `users_data/<uid>/`（画像、对话历史、反馈）
- 记忆系统：`memory_system.py`（短期对话/摘要/长期三层）
- 自我更新数据：`data/`（reflections、profiles、subject_requests 等）
- 公网暴露：trycloudflare 隧道（任何可访问）

### 必须处理的事项
- [ ] **PII 保护**：users.json 存储了用户自我描述、对话内容——需要评估是否含可识别个人信息（姓名/联系方式/地理位置）
- [ ] **传输加密**：公网隧道是 HTTPS（trycloudflare 自带），但需确认本地到隧道的链路 + API 无明文敏感数据
- [ ] **访问控制**：当前公网 URL 无认证——任何人都能访问并创建用户；需评估是否加访问口令/白名单
- [ ] **数据留存策略**：对话历史保留 30 天（server 配置）——需要明确删除机制、用户删除权（GDPR/个保法合规）
- [ ] **未成年人保护**：教育场景可能接触未成年人——需评估儿童个人信息保护（中国《未成年人保护法》+《儿童个人信息网络保护规定》）
- [ ] **API Key 安全**：DEEPSEEK_API_KEY 在 .env/环境变量——需确认不落库、不进 Git

### 合规参考
- 中国《个人信息保护法》（PIPL）
- 中国《数据安全法》
- 《儿童个人信息网络保护规定》

## 二、算法审查（待处理 · 优先级高）

### 现状
- 教学评估（Evaluator）用确定性启发式——可审查、可复现
- LLM 生成内容（Presenter/AnswerSolver）——需审查
- 自我进化（SelfUpdateAgent 建议 + evolve_prompt 补丁）——质量门禁 QualityGate 已有 L1-L4 过滤
- 个体化画像（Individuality 17 维）——需审查是否存在偏见/刻板印象风险

### 必须处理的事项
- [ ] **内容审查**：LLM 输出是否可能含不当内容（政治敏感/暴力/错误价值观）——现有 QualityGate L1 正则是否足够
- [ ] **教育内容正确性**：学科知识是否准确（尤其 v0.25 新增的语言学/大气科学/量子场论）——二测学科专家验收表就是为此设计
- [ ] **算法偏见**：个体化画像是否可能导致"标签化"（如"代数弱"标签固化学生自我认知）——需设计反偏见机制
- [ ] **自我进化审查**：SelfUpdateAgent 自动生成的学科注册 JSON / 提示词补丁——是否有"自动写入前人工确认"环节
- [ ] **透明度**：学生是否知道"老师是 AI"？是否需披露机制
- [ ] **问责**：AI 教学出错时的责任归属

## 三、关键模块备忘（项目核心资产）

### 模块 A：数据存储（05_实现原型/user_store.py + memory_system.py）
- **user_store.py**：用户注册/登录（users.json）+ 学习者画像持久化（users_data/<uid>/profile.json）
- **memory_system.py**：三层记忆（短期对话/摘要压缩/长期）
- **涉及文件**：users.json、users_data/、data/、conversations
- **风险**：users.json 是明文 JSON——PII 风险评估的起点（见上文）
- **演化**：后续若用户量增长，需迁移到数据库（SQLite/PostgreSQL）

### 模块 B：接入的模型（05_实现原型/llm_adapter.py + llm_api.py）
- **create_llm(provider, model)**：provider 支持 auto（默认自动识别）/ mock / deepseek / openai / anthropic
- **当前实际使用**：DeepSeek（OpenAI 兼容 API，.env 或环境变量 DEEPSEEK_API_KEY）
- **架构**：ModelAPI 统一接口 + auto_detect 自动识别 + AdapterLLM 适配层——换模型只需改 provider 参数
- **调用方**：全部 subagent（Diagnostor/Presenter/AnswerSolver/AffectionSupportor/SelfUpdateAgent）+ Individuality 建模
- **风险**：模型输出质量直接影响教学质量——需监控；模型 API 变更/限流需容错（tool_recovery 已处理超时）
- **演化**：可替换/新增其他模型（如国产开源模型本地部署）
