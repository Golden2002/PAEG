## 二、为什么"没体现"——文档记载缺失

约束段是**运行时注入 system prompt** 的动态文本，PDF/技术文档**只记录了旧 3 位掩码**（A/B/C），未更新 8 层结构。**功能已实现，文档滞后**。

## 三、补记（本 memo）

- 8 层约束 = 3 位掩码 0-7 的线性谱（000=层4 全约束 → 111=层7 仅 L0）
- L0 绝对底线（语言规范/格式/反AI腔/安全）永不跳过，任何 mask 都注入
- 教学阶段映射：诊断→L2 / 新授→L3-4 / 巩固复习→L5 / 提高→L6 / 迁移创造→L7
- 用户文本触发：直接要答案→L2 / 要深入→L6 / 要简化→L2 / 危机→L0-1
