## 三、升级方案（Oracle 设计中）

```
Step0 演讲稿生成（LLM）★新增：基于主题/大纲生成完整演讲稿（每页讲解词，教学法+逻辑递进）
Step1 大纲（LLM）：教学式标题
Step2 帧设计：每页画面（字幕/公式/图示）
Step3 配音：edge-tts 读演讲稿（非读标题）
Step4 合成：ffmpeg（每页时长 = 演讲稿朗读时长）
Step5 QA 循环：字幕/时长/音频检查
```

**关键**：演讲稿是视频的"内容支撑"——每页停留时长 = 该页演讲稿朗读时长，字幕 = 演讲稿分句。

## 四、与 PPT pipeline 复用

- 演讲稿 ≈ PPT 的"大纲+要点"扩展（可复用 LLM 大纲规划）
- 帧设计 ≈ PPT 的"视觉设计"（可复用配色/布局方法论）
- QA 循环 ≈ PPT 的转图检查
