## 二、测试发现并修复的问题（P0）

### P0-1：utils 同名冲突 → AffectionSupportor 兜底模板
- **现象**：倾诉 R3 返回固定模板"我听见你说的了...我在这儿陪着你"（0.1s）
- **根因**：`utils.py` 模块与 `utils/` 目录同名冲突，`from utils.constraint_signals import` 失败 → AffectionSupportor 内部 import 异常 → 兜底
- **修复**：utils.py 内容并入 utils/__init__.py（包语义），补 services/handlers/__init__.py
- **验证**：R3 恢复高质量情绪回应（"这句话从小跟着你长大...我想先确认一件事"）

### P0-2：token 预算生命周期累计 → 长会话全系统退化
- **现象**：30-40 请求后，knowledge/method 返固定模板，讲义 0.0s 失败
- **根因**：`_TOKEN_BUDGET_USED` 服务器生命周期累计，超 60000 后 `_safe_chat` 全返回 None
- **修复**：改 60 分钟窗口制（窗口滑动自动重置）
- **验证**：重启后 knowledge 恢复 1011 字详细清点

### P0-3：服务器长跑后 LLM 状态退化（Oracle 分析中）
- 现象：即使预算窗口制，长时间运行后仍偶发 LLM 立即失败
- 状态：Oracle 后台分析根因（连接池/超时/重试）
