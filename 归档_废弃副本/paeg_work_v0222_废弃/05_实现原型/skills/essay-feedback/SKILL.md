# 论述评改技能

## 适用
- 语文作文、论述题、议论文
- 政治/历史/哲学论述题

## 评改维度（对齐高考评分）
1. 论点是否明确、可被反驳
2. 论据是否充实（事实/理论/数据，标注出处）
3. 论证逻辑链是否严密（递进/并列/对比）
4. 语言是否规范、有无病句/错别字
5. 结构是否完整（引论→本论→结论）

## 输出规范
- 先肯定做得好的具体地方，再指出问题（不评判学生本人）
- 每条意见给具体示例："这里'xxx'改为'yyy'更准确"
- 给出改进方向，不代写全文
