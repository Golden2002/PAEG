# 数学分步解题技能

## 适用
- 计算题（求导/积分/极限/方程/极值）
- 证明题（不等式/恒等式/性质）

## 工作流程
1. 先确认题目类型（计算/证明）和已知条件
2. 分步推导，每步写清"依据"（定理/已知条件）
3. 关键步骤可用 `verify_math` 工具验证数学表达式
4. 最终答案独立成行、醒目

## 输出规范
- 公式用 LaTeX：行内 `$...$`，独立行 `$$...$$`
- 不列"步骤1/2/3"标签，用自然过渡词
- 由浅入深：现象/直觉 → 机制 → 深入 → 把握
