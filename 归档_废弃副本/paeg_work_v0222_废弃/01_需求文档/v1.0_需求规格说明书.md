## 1. 项目重写：清晰、准确、系统的指令

### 1.1 项目目标（Goals）

构建一个名为 **PAEG（Pedagogical Agent with Evolving Growth）** 的教育者智能体，满足以下两个核心目标：

| # | 目标 | 可观测的成功标准 |
|---|---|---|
| **G1** | **自我懂得** | Agent 拥有"对自己架构和能力的元认知"（metacognition）—— 能解释自己的设计、能诊断自己的故障、能规划自己的改进 |
| **G2** | **自我更新** | Agent 能基于交互结果自动改进：①更新知识库；②调整教学策略；③扩展能力集；④记录学习历史 |
| **G3** | **教学：学科知识** | 能教授高中 + 本科水平的学科（文、理、工、医、商、艺术等） |
| **G4** | **教学：技能** | 能教授可操作技能（编程、写作、绘画、思考方法、问题解决等） |
| **G5** | **教学：人之为人的素养** | 能培养审美能力、道德判断力、思辨能力、生命现象学素养 |
| **G6** | **个人化** | 根据学习者画像（年龄、背景、目标、认知风格）调整教学 |

### 1.2 项目范围（Scope）

**In-Scope**：
- 教育者 Agent 的**功能描述与架构设计**（本项目核心交付物）
- 教育者 Agent 的**最小可运行原型**（Python / TypeScript）
- 关键模块的**实现示例代码**（自我更新、教学推理、个性化）
- **测试用例**与**验证标准**
- **教学知识库**的结构定义（学科+素养）

**Out-of-Scope**：
- 完整训练一个教育大模型（仅做 LoRA 微调示例）
- 商业化部署
- 完整 UGC 内容平台
- 法律合规审核

### 1.3 关键约束（Constraints）

| 类别 | 约束 |
|---|---|
| **技术** | 必须基于现有大模型 API（Anthropic / OpenAI / DeepSeek 等），不训练基座 |
| **架构** | 复用本知识库中已验证的"7 大 Agent 机制"（Agent Loop / Tool Use / Task Planning / Context Management / Subagent / Skill / Goal Mode） |
| **教学** | 必须支持中文为主、英文为辅；必须能解释（不只是给答案） |
| **自我更新** | 必须是"安全的、版本化的、可回滚的"，不能破坏已有知识 |
| **成本** | 单次教学交互的 token 消耗 ≤ 5,000；自我更新批处理 ≤ 50,000 |
| **可测试** | 每个能力有可自动判分的测试用例 |

### 1.4 交付物（Deliverables）

| 交付物 | 类型 | 验收标准 |
|---|---|---|
| **D1** | 需求规格说明书（本文件） | 包含所有 G1-G6 的可观测标准 |
| **D2** | Agent 架构设计书 | 含模块图、状态机、数据流、API 规格 |
| **D3** | 教学知识库 schema | 高中 + 本科 + 素养三大类，含可扩展字段 |
| **D4** | 最小可运行原型 | 跑通 G3 + G4 一例，输出教学对话 |
| **D5** | 自我更新机制实现 | 跑通"基于一次对话更新知识"端到端 |
| **D6** | 测试用例集 | ≥ 20 个，自动判分 |
| **D7** | 教学示例对话集 | ≥ 5 段（含高中、本科、素养各 1-2 例） |

### 1.5 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 模型产生幻觉 | 学生学到错误知识 | 强制要求"给出可验证的依据"；教学有"事实 vs 解释"两层 |
| 自我更新引入错误 | 系统退化 | 版本控制 + A/B 测试 + 回滚机制 |
| 学科覆盖不全 | 教学不均衡 | 设计可扩展知识库 schema；先打样后扩展 |
| 教学风格单一 | 不能个性化 | 学生画像 + 多种教学策略库 |
| 道德思辨问题敏感 | 价值观风险 | 教学层有"安全中间件"；明确"我们不教什么" |

### 1.6 验收里程碑

| 里程碑 | 时间 | 通过条件 |
|---|---|---|
| M1：需求确认 | Step2 完成后 | 用户批准 v1.0 需求 |
| M2：架构草图 v1.0 | Step3a 完成后 | 含核心组件 + 数据流 |
| M3：架构定稿 v2.0 | Step3c 完成后 | 包含自我更新、教学推理、个人化 |
| M4：原型可跑 | Step3d 后 | G3 + G4 demo 跑通 |
| M5：测试通过 | 最终 | ≥ 20 个测试用例通过 |

## 2. 名词表

| 术语 | 含义 |
|---|---|
| PAEG | Pedagogical Agent with Evolving Growth，本项目代号 |
| 自我懂得 | Agent 对自身架构、能力、状态、限制的元认知 |
| 自我更新 | Agent 通过反思、记忆、规划等机制持续改进自身 |
| 教学推理 | 在教学场景下的多步推理：诊断→计划→呈现→反馈→调整 |
| 学习者画像 | 学生的年龄、目标、背景、认知风格、情感状态的综合表征 |
| 学科知识 | 高中 + 本科水平的结构化知识 |
| 人文素养 | 审美、道德、思辨、生命现象学等"成为完整的人"所需的能力 |
| Skill | 按需激活的专业知识块（来自知识库 L1-03） |
| Metacognitive Loop | 监控-评估-调整的元认知循环 |
