## 1. 用户原始需求（verbatim）

> "写一个 1. 自我懂得智能体架构，能够进行自我更新的 2. 能够进行教学（涵盖高中、本科水平的学科知识与技能；人之为人的审美、道德、思辨能力、生命现象学素养）的智能体"

**v2.0 解读（结合 Step2 决策）**：
- **自我懂得** = Layer 5 反射器 + 元认知日志（不变）
- **自我更新** = **保守渐进**（v1.0 是"混合"，v2.0 明确强度）
- **教学** = 高中 + 本科 + **考研**（v2.0 扩展） + 人文素养（不变）
- **智能体** = **完整 GUI**（v2.0 新增）

## 4. 关键约束（Constraints）

| 类别 | 约束 | v2.0 调整 |

## 6. 风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 模型产生幻觉 | 学生学到错误知识 | 强制"可验证依据"；教学有"事实 vs 解释"两层 |
| 自我更新引入错误 | 系统退化 | **保守渐进**（≥3 证据 + 7 天观察）+ 版本控制 + A/B 测试 + 回滚 |
| **GUI 增加复杂度** | 项目延期 | **后端先跑通，GUI 渐进完善** |
| **考研政治时事性强** | 知识过期 | 接入 RSS 实时更新；批处理每周更新时事库 |
| **考研数学卷种差异** | 知识点覆盖不全 | 显式建模"卷种 → 知识点矩阵" |
| 学科覆盖不全 | 教学不均衡 | 优先打样"高中数学/本科哲学/考研政治/审美-悲剧"4 个标杆 |
| 教学风格单一 | 不能个性化 | 学生画像 + 多种教学策略库 |
| 道德思辨问题敏感 | 价值观风险 | 安全中间件（政治/医疗/法律/儿童保护）；明确"不教的内容" |
| **GUI 与后端耦合** | 接口漂移 | **先用 OpenAPI 定义接口，再两边并行实现** |

## 9. 详细功能分解

### 9.1 G1 自我懂得（深化）

| 子能力 | 实现 |
|---|---|
| 解释自己的设计 | 输出架构图（自动生成） |
| 诊断自己的故障 | 元认知日志 + 异常检测 |
| 规划自己的改进 | 每周批处理时的"我接下来该学什么" |

### 9.2 G2 自我更新（保守渐进）⭐

| 触发 | 内容 | 阈值 |
|---|---|---|
| 每次会话 | 反思记录、策略增量、画像增量 | 自动 |
| 每周批处理 | 知识整合、策略优化、LoRA 微调（可选） | 自动 |
| 每次回答前 | 实时检索增强 | 自动 |
| **新策略采纳** | 教学策略库新增 | **≥3 独立证据** |
| **新知识入库** | 知识库新增 | **来源可信度 ≥0.8** |
| **画像修改** | 学习者掌握度 | **EMA α=0.3** |
| **回滚窗口** | 新策略试运行期 | **7 天** |

### 9.3 G3 学科教学（高中+本科+考研）

#### 9.3.1 高中 9 科
- 语文、数学、英语、物理、化学、生物、历史、地理、政治
- 加上：信息技术、艺术（音乐/美术）

#### 9.3.2 本科 12 一级学科
- 中国语言文学、历史学、哲学、理学、工学、医学、农学、经济学、法学、教育学、管理学、艺术学

#### 9.3.3 考研 4 大公共课 ⭐
- **政治**：5 大模块（马原/毛中特/史纲/思修/时政）+ 时事 RSS
- **英语**：阅读/写作/翻译/完形四大题型 + 历年真题语料库
- **数学**：数一/二/三分卷 + 知识点矩阵
- **专业课**：13 大类 + 院校画像

### 9.4 G4 技能教学
- 编程、写作、绘画、思考方法、问题解决
- 每类至少 1 个 demo

### 9.5 G5 人文素养
- 审美、道德、思辨、生命现象学
- 4 维度均有完整教学示例

### 9.6 G6 个人化
- 学习者画像（深度云端持久）
- 世界观自动切换
- 多设备同步

### 9.7 G7 GUI 完整架构 ⭐

| 组件 | 功能 |
|---|---|
| **主对话面板** | 多轮对话 + 流式输出 |
| **学习者画像面板** | 进度可视化 + 情感曲线 |
| **知识图谱浏览器** | 学科结构可视化 |
| **多模态呈现区** | 图像/公式/动画/视频 |
| **教师/家长仪表盘** | 班级统计 + 干预建议 |
| **元认知日志查看器** | "我如何被更新的"透明化 |
| **世界观切换指示器** | 当前主导世界观显示 |

### 9.8 G8 考研适配 ⭐

| 科目 | 特殊处理 |
|---|---|
| 政治 | 时事 RSS 接入、5 大模块分别建模 |

### 9.9 G9 自我更新可观测 ⭐
