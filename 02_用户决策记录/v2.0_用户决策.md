## D1. 核心定位与边界

### D1.1 PAEG 是**完整教育者 Agent**（已确认）

| 维度 | 决策 | 影响 |
|---|---|---|
| **定位** | 独立完整产品：能教所有学科、能教人文素养、能自适应 | 面向终端学习者的完整产品 |
| **不** | ❌ 仅做框架（不做具体教学场景） | 必须有具体的教学能力 |
| **不** | ❌ 仅做学科教练（不做素养） | 必须兼顾知识 + 素养 |
| **不** | ❌ 仅做人文导师（不做学科） | 必须兼顾知识 + 素养 |

### D1.2 PAEG 应该是**带 GUI 的完整智能体架构** ⭐ 新增

这是本次 Loop 的**重大扩展**。原 v1.0 仅设计了"对话式"接口。v2.0 必须包含：

| UI 组件 | 功能 | 技术选型候选 |
|---|---|---|
| **主对话面板** | 多轮对话、流式输出 | React + WebSocket |
| **学习者画像面板** | 可视化进度、情感曲线 | ECharts / Recharts |
| **知识图谱浏览器** | 学科结构可视化 | D3.js / Cytoscape.js |
| **多模态呈现区** | 图像、公式、动画、视频嵌入 | HTML5 Canvas / Video |
| **教师/家长仪表盘** | 班级统计、干预建议 | React + Ant Design |
| **元认知日志查看器** | "我如何被更新的"透明化 | Markdown 渲染 |
| **世界观切换指示器** | 显示当前主导世界观 | 颜色 + 图标 |

## D3. 自我更新策略：**保守渐进**（维持 v1.0）

**决策**：维持 v1.0 保守渐进策略

| 机制 | 频率 | 触发条件 | 实现 |
|---|---|---|---|
| **渐进式增量** | 每次对话结束 | 自动 | 写入本地（git-like）+ 同步云端 |
| **批处理离线** | 每周一次 | cron 调度 | 后台任务：知识整合、策略优化 |
| **实时检索增强** | 每次回答前 | 自动 | RAG over 外部知识库 |

### D3.1 保守渐进的具体规则

| 规则 | 阈值 | 说明 |
|---|---|---|
| **新策略采纳** | ≥ 3 个独立证据 | 防止过早收敛 |
| **新知识入库** | 来源可信度 ≥ 0.8 | 学术权威 > 个人观点 |
| **画像修改** | EMA α = 0.3 | 单次会话对长期画像影响有限 |
| **元认知反思** | 每次会话 + 每周批处理 | 三段式（每步/每会话/每周） |
| **回滚窗口** | 7 天观察期 | 新策略小范围试 7 天 |
| **用户可见** | 永远 | 学习者可看"我如何被更新的" |

### D3.2 安全三原则（不变）

1. **版本化**：所有写入走 git-like 存储（可回滚到任意版本）
2. **A/B 测试**：新策略先小范围试，再全局
3. **用户可见**：学生可访问自己的"被更新历史"
