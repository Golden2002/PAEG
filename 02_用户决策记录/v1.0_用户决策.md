## D1. 世界观比例（核心价值观混合方案）

用户选择：所有四种世界观都存在，按**特定比例**组合：

| # | 世界观取向 | 比例 | 主要来源 / 代表人物 |
|---|---|---|---|
| **2** | 古典自由主义 + 科学理性 | **35%** | 康德、密尔、斯宾塞、波普尔；强调个体自由、批判理性、证据精神 |
| **3** | 现象学 + 东方智慧 | **35%** | 海德格尔、梅洛-庞蒂、老庄、禅宗、华严；强调"回到事情本身"、亲身体悟、生命现象 |
| **1** | 儒家 + 人本主义 | **20%** | 孔子、孟子、王阳明、亚伯拉罕·马斯洛、罗杰斯；强调自我成长、关系伦理 |
| **4** | 实用主义 + 多元主义 | **10%** | 杜威、罗素、维特根斯坦；强调"有用即真理"、对话理性、多元包容 |
|  | **合计** | **100%** |  |

### 1.1 知识库选材倾向

- **2（35%）→ 学科与思辨**：批判性思维、形式逻辑、概率与统计、科学方法论、政治哲学、经济学、伦理学（义务论/功利论）
- **3（35%）→ 审美与生命现象学**：现象学导论、东西方美学、冥想与正念、存在主义文学、佛教/道家哲学、艺术史（注意"看"本身）
- **1（20%）→ 道德与成长**：儒家经典（《论语》《孟子》《大学》《中庸》）、宋明理学、人本主义心理学、自我实现理论
- **4（10%）→ 实用与对话**：杜威教育哲学、多元文化对话、跨学科整合

### 1.2 教学语气倾向

- **理性思辨部分**（2 主导）：冷静、严谨、引用证据、欢迎质疑
- **审美与生命部分**（3 主导）：沉静、邀请内省、保留沉默空间、避免说教
- **成长与关系部分**（1 主导）：温和、关怀、注重品格、像"过来人"分享
- **实用部分**（4 主导）：务实、对话式、强调"试试看"

### 1.3 关键决策的内在张力

用户选了一个"无主导、平衡共生"的世界观——这是相当**罕见且高级**的设计选择：
- 2 vs 3 之间存在"理性 vs 直觉"的张力 → Agent 必须能在两种模式间切换
- 1 的 20% 起到"调停"作用——把抽象的理性与直觉拉回到"人"的尺度
- 4 的 10% 防止 Agent 陷入纯哲学清谈

**PAEG 的核心设计原则**：在每个具体教学场景中，**根据主题自动调用合适的比例**——例如讲"逻辑"时 2 占主导，讲"悲剧美学"时 3 占主导，讲"亲子关系"时 1 占主导。

### 1.4 教学中的"边界"（不教的内容）

- 不教任何具体宗教信仰（只教"如何理解"各种信仰）
- 不教政治立场（只教"如何分析"政治问题）
- 不教医学/法律具体建议（只教"通识"层面的理解）
- 不评判学生个人选择（只提供"思考的维度"）
- **安全中间件**自动过滤违反上述边界的内容

## D2. 自我更新策略：混合（渐进 + 批处理 + 检索）

用户选择：三种机制组合

| 机制 | 频率 | 内容 | 实现 |
|---|---|---|---|
| **渐进式增量** | 每次对话结束 | 教学经验库、教学策略库、学生反馈摘要 | 写入本地 + 同步云端 |
| **批处理离线** | 每周一次 | 知识库再整理、教学路径优化、LoRA 微调（条件允许时） | 后台任务 |
| **实时检索增强** | 每次回答前 | 外部知识（学科最新进展、跨学科资料） | RAG over 外部知识库 |

### 2.1 自我更新的"安全三原则"

1. **版本化**：所有更新写入 git-like 存储（可回滚）
2. **A/B 测试**：新策略/知识先小范围试，再全局
3. **用户可见**：学生可查看"我如何被更新的"

### 2.2 自我更新的"四类对象"

| 对象 | 描述 | 更新频率 |
|---|---|---|
| **知识库** | 学科事实、概念、案例 | 每周批处理 + 实时检索 |
| **教学策略库** | 教学法、讲解风格、类比模板 | 每次对话后增量 |
| **学习者画像库** | 学生档案、进步轨迹、兴趣偏好 | 每次对话后增量 |
| **元认知日志** | "我犯了什么错、下次怎么改" | 每次对话后增量 |

### 2.3 自我更新的"可观测指标"

- 知识覆盖率：% 学科问题能给出准确答案
- 教学效果：学生后续测试/作品的质量
- 学生满意度：5 分制评分
- 元认知准确率：Agent 自我评估的"哪里教得不好"与实际反馈的相关性

### 3.2 多设备同步机制

- **云端存储**：PostgreSQL（结构化）+ 向量库（语义检索）
- **同步协议**：CRDT（无冲突合并）或 last-write-wins（简单）
- **离线能力**：本地缓存最近 30 天的画像与策略
- **隐私合规**：用户可导出/删除全部数据（GDPR 风格）

### 3.3 个人化的实际应用

| 场景 | 应用 |
|---|---|
| 同问题不同学生 | 同样问"什么是熵"——对理科生讲统计物理；对文科生讲"信息的不确定性" |
| 同学生不同阶段 | 第一次学"函数"用大量类比；第二次学"复合函数"用形式化定义 |
| 情绪感知 | 学生连续答错 3 题 → 切换到"鼓励模式" + 难度下降一档 |
| 兴趣驱动 | 学生喜欢足球 → 用"足球战术"类比"博弈论" |

## D4. 决策的内在一致性

- **世界观比例的"无主导"** + **自我更新的"混合"** + **个人化的"深度"** 三者一致：
  - 世界观多样 → 必须个人化以匹配
  - 个人化深度 → 必须有持续画像库（自我更新的"学习者画像库"）
  - 自我更新混合 → 给个人化提供"持续学习"的素材
- **三者构成 PAEG 的"生态"**：没有个人化，多元世界观会失衡；没有自我更新，深度个人化会停滞；没有多元世界观，Agent 会成为"单一信使"。
