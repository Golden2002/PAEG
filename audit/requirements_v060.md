## 一、意图路由修复（用户实测 Bug）

### 1.1 Bug：自我指涉误判知识库
**现象**：问"你有哪些功能"输出知识库检索（用户实测）

**根因（3 层）**：
| 层 | 问题 | 修复 |
|---|---|---|
| P0 | /api/knowledge 无 is_interface_query 拦截 | ✅ 已加（L3953 前）|
| P1 | is_knowledge_query 误判"你会什么" | ✅ 已加明确能力类反向排除 |
| P2 | INTERFACE_QUERY_PATTERNS 缺身份模式 | ✅ 已补"你能做什么/你是谁"|

**用户关键指示**：ambiguous 输入（"你学过什么"）**由 LLM 判断**（knowledge vs interface），INTENT_PROMPT 已补示例。

**验证**：
- "你有哪些功能" → interface（0.2s 确定性模板）✅
- "你学过什么" → knowledge（12.4s 库清点）✅
- "你会什么/你懂什么/你了解什么" → knowledge ✅

### 1.2 乱码/无意义快速兜底（测试发现）
**现象**：knowledge 的乱码输入（zzz/asdfgh/！！！）触发 LLM 推理 78s

**修复**：新增 `utils/gibberish.py` 乱码检测（纯符号/键盘串/单字母重复/内容重复），命中走快速兜底（0.2s，390x 加速）。

**验证**：zzz→0.2s、asdfgh→0.0s、！！！→0.0s；正常输入不受影响（查X→knowledge 21.7s、你有功能→interface 0.0s）
