## 3. 测试中发现并修复的问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | GBK 控制台无法输出 ✓ 字符导致测试 print 崩溃 | 测试需 `PYTHONIOENCODING=utf-8` 运行（已加入文档） |
| 2 | Evaluator 使用 random.uniform（v0.2 设计要求确定性） | 重写为确定性启发式评分 |
| 3 | `_reflect` 空评估列表 ZeroDivisionError | 加空值守卫 |
| 4 | LLM 诊断过度保守导致 ready_to_teach=False、教学退化 1 步 | 就绪度改规则判定，LLM 只做深度/缺口分析 |
| 5 | SessionContext 缺 session_id（server 依赖） | 补充唯一 ID 字段 |
| 6 | `_log` replaceAll 误伤自身导致无限递归 | 修正方法体 |
| 7 | 端口 5000 残留 v0.2 时代旧 server 进程 | 终止旧进程（新 server 绑定失败被掩盖） |
| 8 | 旧接口不兼容（kb.stats/search_subjects、create_llm、tone_info 参数） | 兼容垫片 + 统一 llm_api 层 |
