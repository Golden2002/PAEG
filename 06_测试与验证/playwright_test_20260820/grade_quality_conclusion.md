# 学段×学科 教学质量验证结论（2026-08-20 · §3.79 Round 8）

## 验证方法
1. **接线层（单元验证）**：`build_presenter_system(subject, tone, learner{grade})` 对 4 学段逐一检查——学段骨架段名（GRADE_SCAFFOLDS）+ 深度阶梯（SUBJECT_GRADE_DEPTH：scope/必须出现/避免/示例）。
2. **输出层（真实调用）**：`grade_quality_probe.py` 真实 POST `/api/teach/stream`（携带 grade_level），抓 presentation 输出，按学段期望特征正则检查（对应 GRADE_SCAFFOLDS 段名与用户需求：大学生 lecture 式/方法论/题型/举一反三）。

## 结论

### ✅ 接线真实联通（4/4 学段全过）
- 初中：现象钩子/画面示意/类比/命名/复述触发 骨架段 ✅ + 深度阶梯（数感直观）✅
- 高中：定义/公式定理/典型例题/误区/知识结构图 ✅ + 深度阶梯（函数导数）✅
- 大学本科：**严格定义/定理框架/关键推导/应用/学科视野** ✅ + 深度阶梯（分析基础）✅——满足"lecture 式讲解 + 高屋建瓴方法"要求
- 考研：**考什么/怎么考/解题套路/真题演示/易错点清单** ✅ + 深度阶梯（考点解剖/踩分）✅——满足"题型讲解 + 得分步骤"要求
- 学科方法论（method_guide 11 科）+ 概念图谱（前驱提示）也注入同一 system

### 🟡 输出层：LLM 对学段特征遵循度参差（内容质量指标）
| 学段 | 特征通过 | 说明 |
|---|---|---|
| 初中 | 3/3 | 感官/可视化/复述引导 全过 |
| 高中 | 2/3 | 缺"反例/误区" |
| 大学 | 2/3 | 缺"应用/学科视野" |
| 考研 | 0/3 | 样本未体现考点/题型/易错字样 |

**性质**：不是接线缺口（system 已含全部学段约束），而是 **LLM 对长 system prompt 中学段骨架的遵循漂移**（单样本；考研 47s/1392 字为一次采样）。这也是"输出内容质量"指标的真实反映。
