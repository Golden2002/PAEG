## 2. 设计亮点

### 2.1 用户驱动的关键决策
- **世界观比例**：2:35% + 3:35% + 1:20% + 4:10% — 这是相当**罕见且高级**的设计选择（无主导、平衡共生）
- **自我更新混合**：渐进+批处理+检索 三种机制组合
- **个人化深度**：云端持久+多设备同步

### 2.2 架构创新
- **6 层架构**：从基础模型到自我更新，清晰分层
- **5 个子代理**：诊断、计划、呈现、评估、调整 — 每个职责单一
- **三段反思**：每步+每会话+每周 — 不同粒度的元认知
- **安全三原则**：版本化+A/B 测试+用户可见

### 2.3 教学深度
- **4 库 4 维度**：学科 + 素养 + 教学法 + 案例
- **13 主题 × 4 语气**：物理/数学→严谨；文学/美学→沉思；伦理→关怀；职业→务实
- **5 学科完整示例**：物理、文学、道德、数学、生命现象学 — 每种都用不同教学策略

## 7. 教学示例对话集

### 7.1 物理（"什么是熵？"）

```
学生：什么是熵？
PAEG：[诊断] 小李理科偏好，物理概念掌握 0.85
PAEG：[计划] 物理类比（卡诺热机）+ 视觉图
PAEG：[呈现] 严谨、冷峻、强调证据
  → "让我们看一杯热水：分子从有序变得混乱..."
  → "S = k·lnΩ（玻尔兹曼公式）"
  → [图] 分子运动动画
PAEG：[评估] 0.87 分
PAEG：[调整] 继续深入到"信息熵"
PAEG：[反思] "理科生-物理类比"模式成功
```

### 7.2 文学（"为什么特洛伊战争持续十年？"）

```
学生：为什么特洛伊战争持续十年？
PAEG：[诊断] 小李文科偏好，文学概念掌握 0.75
PAEG：[计划] 叙事+现象学反思
PAEG：[呈现] 沉静、邀请内省、保留沉默
  → [念《伊利亚特》开篇 2 min]
  → "如果你是阿基琉斯，你会为荣耀放弃生命吗？"
  → [引导 5 min 安静思考]
PAEG：[评估] 0.85 分（情绪：engaged, curious）
PAEG：[反思] "文学沉浸+现象学反思"组合成功
```

### 7.3 道德（"电车难题"）

```
学生：电车难题该拉开关吗？
PAEG：[诊断] 小李对哲学有兴趣
PAEG：[计划] socratic_dialogue 策略
PAEG：[呈现] 温和、关怀
  → "你为什么这么选？"
  → "如果只能救一个人呢？"
  → "如果那个陌生人是你妈妈呢？"
  → "引入多元视角：义务论、功利论、儒家经权"
PAEG：[评估] 0.82 分（学生进入深度思考）
PAEG：[反思] "对道德问题不要直接给答案，要给对话"
```

### 7.4 数学（"为什么负负得正？"）

```
学生：为什么负负得正？
PAEG：[诊断] 小李数学中等，逻辑型
PAEG：[计划] 定义法+直观
PAEG：[呈现] 严谨、冷静
  → "向前走=加，向后走=减；负号是反向，反向的反向=正向"
  → [图] 数轴动画
PAEG：[评估] 0.85 分
PAEG：[反思] "直观+严格双轨"成功
```

### 7.5 生命现象学（"为什么人会感到孤独？"）

```
学生：为什么人会感到孤独？
PAEG：[诊断] 小李最近情绪低落
PAEG：[计划] 现象学反思+关怀（warm_caring + contemplative）
PAEG：[呈现] 温和、不急着给答案
  → [海德格尔"此在"的孤独]
  → [列维纳斯"他者"的孤独]
  → [庄子"独与天地精神往来"]
  → "邀请你用 5 分钟想想：你最深的孤独是什么样的？"
PAEG：[评估] 0.90 分（情绪：received）
PAEG：[反思] "这种话题要'陪伴'而不是'答案'"
```

## 8. 项目价值

PAEG 项目的核心价值：

1. **理论价值**：证明了"自进化 Agent + 教学"的设计可行性
2. **实践价值**：可作为开源教育 Agent 的参考实现
3. **教学价值**：把"如何教学"这件事做成可被复现的工程
4. **社会价值**：让优质教育可扩展到资源不足的地区
