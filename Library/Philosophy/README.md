# 目录占位

本目录是 PAEG 知识库结构的一部分。实际资料文件（PDF/词汇表/哲学文本等）体积较大，
未直接上传 GitHub——从仓库拉取代码后，在本地项目对应目录放入资料即可恢复完整功能。

## 本目录预期内容

- **Language**：英语词汇扩充 1-8（7天×30词）、GRAMMAR大观、德语 A1 手册、高阶词汇表
- **Philosophy**：汉斯·约纳斯《生命现象》《责任原理》、哲学随笔集
- **Simone Weil**：薇依著作（《重负与神恩》《科学与我们》《超自然认识》等 PDF + 文选 docx）
- **user_qa_lib**：用户上传的资料（自动生成）

## 如何恢复

1. git clone 本仓库
2. 将本地备份的资料文件放入对应目录
3. 重启 server，library_loader 会自动扫描加载
