## 一、发布通道（Canary 阶梯）

| 阶段 | 流量比例 | 闸门（通过才进入下一阶段） | 观察期 |
|---|---|---|---|
| C1 canary | 1-5% | 错误率 ≤ 0.5% 且 P95 不劣化 >20% 且 eval pass rate 不降 | 24h |
| C2 early | 20% | 同上 + 无 P0 上报 | 24h |
| C3 majority | 50% | 同上 + 反馈正常 | 24h |
| C4 full | 100% | 全量 72h 无回滚触发 | 72h |

**现状**：PAEG 单机部署（Docker/gunicorn threaded），无多实例流量切分基础设施。
灰度落地路径（渐进）：
1. **配置级 canary**：`paeg_modules.json` 模块门控（即 kill switch）+ `config/agents.json`
   模型路由（如 reasoner 新模型先 C1 档配给 5% 用户组）——**已具备，见 §二**
2. **用户组灰度**：`SESSIONS`/画像 `cohort` 字段（v0.75+）按 uid 哈希分桶（5% 桶启用新特性）
3. **多实例**（学校级部署）：Nginx upstream 按 weight 切流 + `/api/health` 存活探针（已具备）

## 二、Kill Switch（60s 止损）

**主开关 = module_registry 门控**（`paeg_modules.json`，热重载）：
- `is_enabled("ppt")` / `require_module("history")` 等——任一功能可秒级关闭
- 切换命令：改 `paeg_modules.json` → 服务热重载（已有 config 热重载机制）
- **无需重启**（module_registry._load_config 带缓存失效）

**应急开关**：
- 模型降级：`PAEG_REASONING=off`（思考模式开关，已有）
- 联网降级：`PAEG_LESSON_NO_WEB=1`（备课联网闸门，§3.78 新增）
- 整机：`docker compose down` / 杀进程（详见维护手册 §18.22 进程 SOP）

## 三、Rollback（5min 回滚）

1. **代码回滚**：`git revert <commit>` 或 `git checkout <上一版本> -- <文件>`（先备份未提交改动，纪律 17）
2. **数据回滚**：JSON 原子写（tmp+os.replace）天然防半写；自我更新 7 天观察期 + 版本化（G2/G10）
3. **模型回滚**：`config/agents.json` 切回上一模型版本（模型升级视为代码变更，D3）
4. **验证**：回滚后跑 `python smoke_test.py` + `pytest tests/ -q`（检视铁律 5 命令）

## 四、SOP 速查

```
发现 P0 缺陷（线上）
  ├─ 60s 内：module_registry 关闭出问题模块（kill switch，热重载）→ 止损
  ├─ 5min 内：git revert 代码 + 切回模型版本 → smoke_test 验证
  └─ 72h：复盘 → 补回归测试（缺陷进入 golden set）→ 重新走 C1 canary
```
