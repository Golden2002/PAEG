# 导数笔记（高中·学生版）

## 一、为什么要学导数？

**核心问题**：函数图像“弯”的，怎么描述它变化的快慢？

**思路**：平均变化率 → 瞬时变化率（极限思想）

---

## 二、核心概念

### 1. 平均变化率

$$k = \frac{\Delta y}{\Delta x} = \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

几何意义：**割线斜率**

### 2. 瞬时变化率（导数）

$$f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}$$

几何意义：**切线斜率**

> 📌 记忆点：平均→割线，瞬时→切线，中间隔着“极限”。

---

## 三、导数的几何意义

- $f'(x_0)$ = 曲线 $y=f(x)$ 在点 $(x_0, f(x_0))$ 处的**切线斜率**
- 切线方程：$y - f(x_0) = f'(x_0)(x - x_0)$

> ⚠️ 易错：过某点的切线 ≠ 在某点的切线（可能切点不在这点）

---

## 四、基本导数公式表（必须背熟）

| 函数 | 导数 |
|------|------|
| $C$（常数） | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\log_a x$ | $\frac{1}{x \ln a}$ |

---

## 五、运算法则

设 $u = u(x)$，$v = v(x)$：

1. 和差：$(u \pm v)' = u' \pm v'$
2. 乘法：$(uv)' = u'v + uv'$
3. 除法：$\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$（$v \neq 0$）
4. **复合函数（链式法则）**：$y = f(g(x))$，则 $y' = f'(g(x)) \cdot g'(x)$

> 📌 口诀：外层求导，内层不动，再乘内层导数。

---

## 六、导数与单调性（重点）

设 $f'(x)$ 在区间 $(a,b)$ 上：

| 条件 | 结论 |
|------|------|
| $f'(x) > 0$ | $f(x)$ 在 $(a,b)$ 上 **单调递增** |
| $f'(x) < 0$ | $f(x)$ 在 $(a,b)$ 上 **单调递减** |
| $f'(x) = 0$ | 可能为极值点（需验证） |

**求单调区间步骤**：
1. 求定义域
2. 求 $f'(x)$
3. 解 $f'(x) > 0$（增区间）和 $f'(x) < 0$（减区间）

> ⚠️ 注意：定义域优先！先看函数在哪有意义。

---

## 七、极值与最值

### 极值（局部）

- **极大值点**：$f'(x)$ 在 $x_0$ 左侧为正、右侧为负（左增右减）
- **极小值点**：$f'(x)$ 在 $x_0$ 左侧为负、右侧为正（左减右增）

**判定方法**（第一充分条件）：

| $x$ | $x_0^-$ | $x_0$ | $x_0^+$ |
|-----|---------|-------|---------|
| $f'(x)$ | + | 0 | − | → 极大值 |
| $f'(x)$ | − | 0 | + | → 极小值 |

**第二充分条件**：$f''(x_0) < 0$ 极大，$f''(x_0) > 0$ 极小（若 $f''(x_0) = 0$ 无法判断）

### 最值（全局）

闭区间 $[a,b]$ 上求最值步骤：
1. 求 $f'(x) = 0$ 的全部解（驻点）
2. 比较：端点值 + 驻点值，最大者为最大值，最小者为最小值

> 📌 极值 ≠ 最值，最值在端点或极值点处取到。

---

## 八、常见题型与思路

### 题型1：求切线方程
- 切点已知 → 直接代入公式
- 切点未知 → 设切点 $(x_0, f(x_0))$，用斜率相等列方程

### 题型2：含参单调性讨论
- 先求导，再看参数对 $f'(x)$ 符号的影响
- 分类讨论：参数取不同范围时，单调区间不同

### 题型3：恒成立问题（$f(x) \geq a$）
- 转化为求 $f(x)$ 的最小值 ≥ $a$
- 或分离参数：$a \leq f(x)$ 恒成立 ⟺ $a \leq f(x)_{\min}$

### 题型4：零点个数问题
- 用导数研究单调性 + 极值符号判断零点个数
- 结合图像（草图）辅助分析

## 九、易错点清单

- [ ] 忘记先求定义域
- [ ] 复合函数求导漏乘内层导数
- [ ] 把“过某点的切线”当成“在某点的切线”
- [ ] 极值点处导数必为 0，但导数为 0 不一定是极值点（如 $x^3$ 在 $x=0$）
- [ ] 最值忘比较端点值
- [ ] 单调区间不能用“∪”连接（如 $(-\infty,0) \cup (0,+\infty)$ 应分开写）
