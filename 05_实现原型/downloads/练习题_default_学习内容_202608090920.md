# 数学 - 函数单调性 练习题

## 一、基础题
1. 已知函数 f(x) = x² - 2x + 3，判断 f(x) 在区间 [1, +∞) 上的单调性，并说明理由。

## 二、进阶题
2. 设函数 g(x) = x + a/x（a > 0），求 g(x) 的单调递增区间，并证明你的结论。

3. 已知函数 h(x) = x³ - 3x，若对任意 x₁, x₂ ∈ [-1, 1] 且 x₁ ≠ x₂，都有 |h(x₁) - h(x₂)| ≤ M |x₁ - x₂|，求 M 的最小值。

## 参考答案与解析

**1. 答案：** f(x) 在 [1, +∞) 上单调递增。  
**解析：** 任取 x₁, x₂ ∈ [1, +∞) 且 x₁ < x₂，则  
f(x₁) - f(x₂) = (x₁² - 2x₁ + 3) - (x₂² - 2x₂ + 3) = (x₁ - x₂)(x₁ + x₂ - 2)。  
因为 x₁ < x₂，故 x₁ - x₂ < 0；又 x₁, x₂ ≥ 1，所以 x₁ + x₂ - 2 ≥ 0。  
当 x₁ + x₂ - 2 > 0 时，f(x₁) - f(x₂) < 0，即 f(x₁) < f(x₂)，函数递增；  
当 x₁ + x₂ - 2 = 0（即 x₁ = x₂ = 1）时，与 x₁ ≠ x₂ 矛盾，故不会出现此情况。  
因此 f(x) 在 [1, +∞) 上单调递增。  
（说明：借助二次函数图像开口向上、对称轴 x = 1 也可以直接判断，但定义法体现了单调性的本质。）

**2. 答案：** 单调递增区间为 [√a, +∞) 和 (-∞, -√a]。  
**解析：** 任取 x₁, x₂ ∈ [√a, +∞) 且 x₁ < x₂，则  
g(x₁) - g(x₂) = (x₁ - x₂) + a(1/x₁ - 1/x₂) = (x₁ - x₂) · (x₁x₂ - a)/(x₁x₂)。  
因 x₁ < x₂，x₁ - x₂ < 0；又 x₁, x₂ ≥ √a，故 x₁x₂ ≥ a，即 x₁x₂ - a ≥ 0，且 x₁x₂ > 0。  
所以 g(x₁) - g(x₂) ≤ 0，即 g(x₁) ≤ g(x₂)，函数在 [√a, +∞) 上单调递增。  
同理可证 (-∞, -√a] 上也单调递增。  
（说明：这里 x₁x₂ - a = 0 时 g(x₁) = g(x₂)，并不影响单调递增的定义，因为单调递增允许相等。关键是理解“差商”的符号由 (x₁ - x₂) 与 (x₁x₂ - a) 共同决定。）

**3. 答案：** M 的最小值为 3。  
**解析：** 由拉格朗日中值定理（或直接观察），  
|h(x₁) - h(x₂)| = |(x₁³ - 3x₁) - (x₂³ - 3x₂)| = |x₁ - x₂| · |x₁² + x₁x₂ + x₂² - 3|。  
问题转化为求 |x₁² + x₁x₂ + x₂² - 3| 在 x₁, x₂ ∈ [-1, 1] 上的最大值。  
令 u = x₁² + x₁x₂ + x₂²，这是关于 x₁, x₂ 的二次型。  
在 [-1, 1]² 上，u 的最大值为 3（当 x₁ = x₂ = 1 或 x₁ = x₂ = -1 时取得），最小值为 0（当 x₁ = x₂ = 0 时取得）。  
因此 |u - 3| 的最大值为 3（当 u = 0 时），故 M 的最小值为 3。  
（说明：此题不能简单用导数求 |h'(x)| 的最大值，因为中值点 ξ 不一定落在 [-1, 1] 内时结论才成立。直接对差商进行估计才是严谨做法。实际上 |h'(x)| = |3x² - 3| 在 [-1, 1] 上的最大值是 3，本题结果与之吻合，但推理路径不同。）
