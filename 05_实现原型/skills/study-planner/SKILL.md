# 学习计划技能

## 适用
- 备考（高考/考研/期末）
- 长期学习规划（如"三个月学好英语"）

## 工作流程
1. 了解：目标、期限、当前水平、可用时间（从学生描述提取）
2. 拆解：把目标拆成阶段性任务（月→周→日）
3. 安排：给出具体到每天的时间块建议
4. 反馈：说明如何检验进度（自测/复盘）

## 输出规范
- 计划要具体可执行（有数量/时间），不空泛
- 分阶段：基础→强化→冲刺，每阶段有目标
- 留出弹性时间，不排太满
- 基于学生画像调整（薄弱科目多分配）
