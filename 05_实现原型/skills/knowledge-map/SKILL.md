# 知识导图技能

## 适用场景（触发关键词）
- "画知识导图" / "列提纲" / "思维导图" / "知识结构" / "知识脉络" / "知识系统"
- "把XX的知识整理成图" / "XX有哪些分支" / "XX的框架是什么"

## 核心目标
把学生问的知识点组织成**分层、可扩展、有逻辑关系的知识地图**——不是罗列，是展示"这个知识点在更大的知识体系中处于什么位置、由哪些子知识构成、彼此如何关联"。

## 工作流程
1. **定位**：确认知识点属于哪个学科、哪个章节（结合 SUBJECT_STYLES 学科体系）
2. **调查**：从知识库（Library/KnowledgeBase）检索该知识点及其前置/后置知识；必要时联网补全
3. **分层**：按"学科 → 章节 → 概念 → 子概念 → 具体细节"组织
4. **关联**：标注各节点之间的关系（依赖/并列/递进/对比/实例）
5. **输出结构化导图**（见输出规范）

## 输出规范（必须遵循）
用 Markdown 嵌套列表呈现知识导图（每层缩进 + 分支），结构如下：

```
## 📍 知识导图：{知识点}

### 知识定位
- 学科：{学科}
- 所属章节：{章节}
- 难度层级：{入门/进阶/深入}
- 前置知识：{列出必须先掌握的知识}

### 主干结构（知识树）
- 第一层：{核心概念 A}
  - 第二层：{A 的子概念}
    - 第三层：{更细的子概念/公式/定义}
    - 第三层：{实例}
  - 第二层：{A 的另一个维度}
- 第一层：{核心概念 B}
  - ...

### 知识关联
- A → B（递进：学 A 是学 B 的前提）
- A ↔ C（并列：两者互为对照）
- D → 应用（D 指向实际应用场景）

### 一句话总结
{用一句话说清这个知识点的核心}

### 学习路径建议
{基于导图给出先学什么、后学什么、重点掌握什么}
```

## 语言要求
- 导图本身用紧凑的分层列表（信息密度高、可扫描）
- 解释性文字克制、完整主谓宾（遵守全局语言规范）
- 不用"震撼/深刻/终极"等 AI 腔词汇
- 公式用 LaTeX（$...$）
