# 概念讲解技能

## 适用
- 任何学科的概念解释（数学/物理/化学/哲学/文学…）

## 工作流程（由浅入深四层）
1. **看见**：用一个具体、可感的现象或例子切入
2. **理解**：讲清机制/原理/为什么（核心，展开讲透）
3. **深入**：与相关知识的联系、边界、历史或前沿视角
4. **把握**：一两句总结 + 抛一个继续思考的问题

## 输出规范
- 用学生生活相关例子承载概念
- 理科给公式和推导思路；文科给论证与反例
- 不列"步骤1/2/3"，用自然连贯的段落
- 可调用 web_search 补充最新资料
