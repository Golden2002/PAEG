### 诊断
用户判断正确：**后端 MCP 工具生态健全，但前端没有正确调用后端能力**。具体缺口：
1. dock 跳转绕过了主 Agent 的 MCP 调度路径（应通过 `/api/chat` 主 Agent 智能调度工具，而非硬编码外链）
2. 前端没有暴露 MCP tools/list 能力发现结果（用户看不到 23 个工具）
3. 无「串联调用」入口（多工具复杂任务无法从前端发起）
