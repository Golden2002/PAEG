## 五、判定结论

### 5.1 总体判定：**尚未完全达到同类顶尖（Rezi/WonderCV/Kickresume 水准）**

**已达成的顶尖项（3 项全达标 + 1 项闭环达标）**：
- **R-04 多版本对比**：产品级三版对比 UI + 可切换，14.6 另有受约束三档方法论；
- **R-06 多格式导出**：HTML/Word/PDF 三格式实测全部可用且一致（PDF 走 Playwright+Chrome 固定资产渲染，含 3 模板+自定义 CSS）；
- **R-07 网页端全链路**：14.5 六步闭环 + 14.6 全流程前端均可跑通；
- **R-08 MCP 插件化**：20 工具 + tools/list + 统一执行契约，已满足"主 Agent 可调度"。

**部分达成（4 项）**：R-01（评分+缺失标注有，JD 关键词解析弱）、R-02（无显式 S/T/A/R 分段、量化不补全）、R-03（ATS 无 JD 关键词覆盖率/阅读顺序）、R-05（14.6 编造率 0 保障充分，但 14.5 产品路径是 3 档简化门）。

**未达成（1 项）**：R-09 双基线融合——L3 内核层未并入 14.5 产品，`core.py` 跨基线导入路径在本机布局下不存在（空操作），06 融合方案未落地、无波次 4 审计文档。产品实际是"14.5 引擎层 + 独立 14.6 内核层"的分置形态，与对标表 R-09"三层架构+能力映射审计无遗漏"的验收指标不符。

### 5.2 缺口清单（如实，按严重度排序）

1. **【高】R-09 融合未完成**：14.5 product 无内核层（experience_draft/bullet_composer/confirmation_gate/12 项 claim_gate 均不在产品包内）；`core.py:34-38` 引用的 `medical-resume-agent/src` 路径不存在（实际 `14.6_medical-resume-agent/src`）→ 跨基线复用为注释承诺；06 融合方案仅停留在文档。
2. **【高】产品事实校验弱于内核**：14.5 `/api/enrich` 以原文为证据且 strength=strong（api.py:74），无 LLM 时启发式拆解全部判 verified；12 项确定性检查只在 14.6 独立可用，产品路径未接线。
3. **【中】中文分词缺失**：`job_evaluation._score_experience`（token 集合重叠）与 `cv_trim._relevance`（按空白分词）对 CJK 文本几乎失效——实测三条目裁剪得分并列 0.3，按原序截断而非按相关性排序；匹配的 experience 维度也仅得基础分。
4. **【中】R-02/R-03 未达验收指标**：无显式 S/T/A/R 四段简历输出、量化数据不补全；ATS 无 JD 关键词覆盖率与阅读顺序检查。
5. **【中】三档规则改写质量**：`multi_version._safe_version` 的"主导"→"参与并承担主要工作于"产生病句"参与并承担主要工作于了"。
6. **【中】前端覆盖面**：14.5 前端仅 7/13 端点（缺 trim/interview/skill-gaps/role-pack 选择），无文件上传；步骤③匹配项恒显"核心技能全覆盖"（引用不存在的 `scores.gaps` 键）；14.6 前端无三版对比 UI、无 Word 导出。
7. **【中】可选依赖门控**：PDF 导出依赖本机 Chrome/Playwright、LaTeX 依赖 lualatex；缺失时降级/报错路径存在，但"排版专业"的 PDF 能力在纯净环境不可用。
8. **【低】14.6 API 无证据时 502**：`/api/resume-rewrites` 在 JD 关键词词表外无命中时返回 502（`no grounded evidence`），无友好降级响应。
9. **【低】文档陈旧**：`product/README.md` 测试徽章 26/26 与现状 109 不符；`product/README.md` 架构图未体现批 A-E 补齐的 20 工具/13 端点。

### 5.3 建议（按优先级）

1. 落地 R-09：在 14.5 product 内建立 `kernel/`（复制/引用 14.6 services 原包）与 `ExperienceKernelPort` 契约，修复 core.py 跨基线路径（或改为显式依赖安装），并补齐波次 4 融合审计文档。
2. 产品路径接入 14.6 12 项 claim_gate（替代 3 档简化门），使 /api/enrich 的 verdict 与内核一致。
3. 为 job_evaluation/cv_trim 引入中文分词（如 jieba）或字面 n-gram 相似度，修复 CJK 相关性评分。
4. ATS 增加 JD 关键词覆盖率与阅读顺序检查（可复用 14.6 resume_intake 的证据匹配词表）。
5. 前端补齐 trim/interview/skill-gaps/role-pack 入口与文件上传；修复步骤③匹配项显示。
