## 检测示例（规则提示）

### 介词规范（v0.25 新增）
- "关于这个知识点，要记住重点。" → 提示："『关于/对于』引出的内容后直接接无主句——介词短语须引出完整主句"
- "通过学习，掌握了很多方法。" → 提示："『通过』须引出对象且后接完整主句"
- "根据教材，讲解了基本概念。" → 提示："『根据』须引出依据且后接完整主句"

### 动宾搭配（v0.20）
- "带着重量" → "这句话的分量很重"
- "做着思考" → "正在思考"

### 省略词形（v0.21.8）
- "觉得倦了" → "觉得疲倦了"
- "道出" → "说出来"

### 悬空宾语（v0.21.8）
- "想与你探讨" → "想与你探讨这个问题"

### 省略主语（v0.14）
- "不催你" → "老师不催你，你慢慢来"

## 统计

- 病句用例：16 个
- 正确句（不误报）：4 个
- 病句捕获率：15/16（119%）
- 正确句零误报：4/4

## 结论

语言规范模块（L1 提示词约束 + L2 规则检测 + L3 LLM 修正）能有效：
1. **捕获介词悬空/误用**（v0.25 新增）
2. **捕获动宾不当**、**省略词形**、**悬空宾语**、**省略主语**
3. **不误报正确句**（4/4 零误报）

→ LLM 输出经过语言规范层后，更接近"真实教师的规范中文"。

（注：16 个病句中 15 个被捕获（94%），唯一放行的"通过这次练习，让学生进步了"因"让"字句已有逻辑主语，判定为可接受的省略；4 个正确句零误报。）
