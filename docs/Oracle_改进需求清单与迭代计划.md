# Oracle 论证记录：四工具顶尖化改进需求清单 + 目标循环迭代计划

> 论证角色：PAEG 工具生态 Oracle 总控官
> 输入：①总审查报告 ②语言规范审查 ③法律检索审查 ④词汇表审查 ⑤简历审查 ⑥架构评估报告 ⑦词汇表范本对标分析
> 论证目标：让四工具产出反复迭代直到达到同类顶尖要求
> 论证方法：证据驱动（全部缺口均回溯到各审查报告 file:line + 实测证据），循环方式 = 实施 → 验证 → 再改进

---

## 〇、总纲（论证基线）

| 结论 | 事实依据 |
|---|---|
| 四工具**均未达顶尖** | 总报告 §一：语言规范 0达标/3部分/4缺失；法律 0达标/9部分/2未达标；词汇表核心管线达顶尖但产品完整性未达标+5缺陷；简历 4达标/4部分/R-09未落地 |
| 根本原因 | 波次 2 设计蓝图（增量顶尖能力）在波次 3 中**几乎全部未落地**，实际交付 = 基线能力保留 + 部分接线 + MCP tools 化 |
| 工具生态适应性 = **优秀**（核心壁垒） | 架构评估 §三：DSH 式插件化 + MCP 三原语 + 独立库桥接 + 动态发现已落地，不需重建 |
| 架构重构债 | 三巨型文件：server.py 3541 / subagents.py 4484 / prompts.py 2805（违反 250 行模块上限） |
| 词汇表产物基准线 | 范本六字段词条 + Zipf 加权（3.0-4.5 黄金区 40%+书内 25%+领域 20%+词源 15%）+ 首次出现排序 + 1000 词 QA，工具必须**超越** |

**优先级口径**：P0 = 产物"干净可交付/正确性硬伤"，不修则产物不合格或空转；P1 = 顶尖能力补齐（对标验收项）；P2 = 生态补全 / 收尾 / 技术债。
